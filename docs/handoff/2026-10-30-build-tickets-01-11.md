## Things to know

- This container can't run downloaded binaries such as vcpkg, so local build tests use a stand-in `VCPKG_ROOT` whose `scripts/buildsystems/vcpkg.cmake` adds a prefix holding the stub libraries built with plain CMake; the real vcpkg runs only in CI. Clang's ThreadSanitizer runtime isn't installed locally either, so those tests run only in CI.
- Debugging CI: the job-log blob host is blocked here; read logs through the GitHub tools' `get_job_logs` with `return_content`. Failing build tests print every error line of the details file and, in the public-map job, vcpkg's per-port error logs.
- Real-library system packages on Linux are listed in the libraries' platform facts and installed by the public-map and eval jobs.
