## Things to know

- This environment can push branches but not tags: publish a map release by running `Release map` with a release name (it tags the commit itself).
- Pushes, pull requests and merges made with a workflow's `GITHUB_TOKEN` start no workflows; the curation and gate workflows dispatch `ci.yml` and `verify-map.yml` explicitly.
- GitHub's API limits unauthenticated requests by address, which shared runners exhaust: the CLI and Automap's CI tools send `GITHUB_TOKEN` when it is set, and a lock's release downloads without the API.
- This session's proxy blocks other repositories' GitHub APIs, so the watcher only runs for real in CI.
- The CLI's tests never reach the network or a CI identity (`clitest` sets release and evidence sources to nowhere and strips `GITHUB_` and `ACTIONS_` variables).
