## Things to know

- vcpkg needs its history for pinned port versions (Jolt's port version 1): CI clones it without blobs, never shallow.
- The ThreadSanitizer build instruments the libraries vcpkg builds too, through an overlay triplet (`TSanTriplet`); with uninstrumented libraries, inline library code in the glue produced false races.
- A seed that isn't caught keeps the failing run's log (or the probe or ThreadSanitizer log) as its details file, `build/automap/seed-<rule>.log`, which the tests print.
- This container can't run downloaded binaries (vcpkg) or clang's ThreadSanitizer runtime: build tests run locally against a stand-in `VCPKG_ROOT` and for real only in CI. Read CI logs through the GitHub tools' `get_job_logs` with `return_content`.
