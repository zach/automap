# Release checklist: automap 0.1.0

The v1 release is a human checkpoint (ADR-0069): the product owner decides it when the four measures are met (ADR-0063). This checklist is what the decision rests on and what publishing it takes.

## The four measures

From one run of the whole eval suite against one map release (SPEC §9.5), filled in from the report's `measures`:

| Measure | Target | Result | Met |
| --- | --- | --- | --- |
| 1. Request to running testbed, warm cache (cold reported alongside) | ≤ 15 min | 26 s warm | yes |
| 2. First-attempt success across eval tasks | ≥ 90% | 14 of 14 (100%) | yes |
| 3a. Catalog libraries with their latest upstream release in the map within 14 days | ≥ 90% | 10 of 11 (91%) | yes |
| 3b. The map's evidence that is current | ≥ 95% | 375 of 375 (100%) | yes |
| 4. Ejected journey compositions that build and pass smoke without Automap | 100% | 14 of 14 (100%) | yes |

Map release: `map-2026.11.06`. Eval run: [42202426559](https://github.com/zach/automap/actions/runs/42202426559) on 2026-11-06. Model: claude-opus-5-5. The run had a warm vcpkg binary cache; a cold figure comes from a run whose cache is empty.

## Before tagging

- [x] Every ticket in `docs/issues/automap-v1/` is done or wontfix, except 19 and 20, which close with the first real upstream release (they don't gate 0.1.0: curation runs daily and the gate merges on evidence).
- [x] `main` is green: CI, Verify map and the reference workflow.
- [x] The public map's newest release is the one the measures were computed against, and every edge's evidence in it is current.
- [x] `README.md` says how to get started, and the install line works against the published release (`go install ...@latest` on 2026-11-06 built a CLI that reads `map-2026.11.06`).

## Publishing

1. Run the `Release CLI` workflow on `main` with version `0.1.0`. It tags `cli-v0.1.0` and publishes one static binary per platform (Linux x64, Windows x64, macOS arm64) with their SHA-256s.
2. Check a published binary: `automap find --json` from an empty directory reports `cli_version` 0.1.0 and the newest map release's libraries, and `automap start --with sdl3 --with dear-imgui:docking --json` reaches probed on one platform.
3. Announce where the product owner chooses.

## After

- Later releases follow semver: patch for fixes, minor for new commands or map formats that stay compatible, major for a format or command that breaks compositions.
